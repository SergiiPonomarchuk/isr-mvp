## Export conventions

- Every record carries `doc_id` (the Firestore document id). Discussion messages carry `msg_doc_id`.
- uid-like fields were coerced to integers: `uid`, `creator_uid`, `submitter_id`, `user_id`, `last_message_sender_uid`, `author_uid`, `in_charge_uid`, and `participants[]`. In Firestore, `participants[]` holds each uid as both string and int, so duplicates appear after coercion. Map keys (e.g. `isr_scores`, `relevance_scores`, `votes`) remain strings, because JSON keys are strings. No non-integer uid values were encountered.
- Removed name fields (PII): `displayName` (3,099 member docs), `last_message_sender_name` (78 issues, 192 discussions), `options[].author_name`, `options[].description[].in_charge_name`, `tasks[].in_charge_name`, `tasks[].comments[].author_name`, `tasks[].subtasks[].in_charge_name`, `tasks[].subtasks[].comments[].author_name`. All other fields are kept verbatim, including Analyzer outputs, scores and `vector_data`.
- Timestamps are ISO-8601 strings. GeoPoints become `{latitude, longitude}`. Firestore Vectors become lists.
- Residual: chat/issue free text contains at-sign mentions of synthetic person names (e.g. "Nathan Lee"). Text was not altered.
