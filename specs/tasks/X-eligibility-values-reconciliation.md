## X schema and new formation-policy contract (implementation proposal)

Confirmed direction: h is a directly affected child/dependent; i is h's parent/carer. Store x_eligible on h.socialRelations's entry for i:

```json
{
  "social_relations_version": "x-links-1",
  "socialRelations": [
    {"relative": 205, "type": "parent", "tie": null, "x_eligible": true},
    {"relative": 206, "type": "sibling", "tie": null, "x_eligible": false}
  ]
}
```

x_eligible is a strict Boolean: if h is a source in the direct cohort, this named relative may be admitted through X. It is directed and per-link, not a global vulnerability label or automatically reciprocal permission. Only true enables the edge; false disables it. Missing/non-Boolean is unknown data, not false and not permission. The versioned source adapter must refuse a new-policy build when a required source's relationship coverage is incomplete, reporting an eligibility-data reason. No automatic inference from age, diagnosis, kinship label or a positive tie; any later population rules require their own reviewed data plan. The field does not change D-family status or semantic embeddings. Never filter/mutate socialRelations in place for other scoring stages.

Preserve current type-to-tie mapping and finite [0,1] custom tie validation. The flag grants edge eligibility; it does not define tie strength. Unsupported relationship type with a true flag requires an explicit valid tie or a declared incomplete-data error. A parent uses current default .2; a newly named carer type gets no invented default. Ignore self-links; do not infer reciprocal links. False links never add membership even with a high tie; a true edge with tie zero still establishes eligibility. Freeze the filtered numeric source links and the relationship-policy identifier into new member evidence for replay/Join.

Proposed boundary, pending the author's clarification: cuts affect the direct candidate pass; marked carers are looked up separately even outside those cuts. This preserves the prior all-eligible-carers/no-second-hop rule. The separate approved CBC-table-only task removes the factor for new scoring; this X proposal does not implement that change.

Use the common PD-9 maximum-mu/maximum-sigma curve. A positive D contribution from another reference cannot be discarded just because one reference's D is zero.
2. Define direct UB_i=sum_j alpha_j*(w_Dj*D_ij+w_Gj*G_i+w_Sj*1), without X. Discard by this bound only for UB_i < Theta, never equality. Rank survivors deterministically by UB descending and stable lexicographic profile ID for ties; retain top 300 and the existing separately identified creator-fetch exception. Record how many hard-gate/pruning/cap exclusions occurred and declare approximate coverage. No claim about scale percentages/performance is accepted without measurements.
3. Let P be that direct candidate set; calculate full per-aspect direct r0. A_seed={i in P:r0_i>=Theta}. This seed set is frozen before step X. All seeds have X=0. Only seeds with at least one x_eligible=true outgoing link need step-X relationship processing.
4. H_i={h in A_seed:h!=i and h explicitly marks its outgoing link to i true}. Look up each distinct marked target once, including outside P; compute its complete D/G/S and E for scores/ceilings/normalization. Hard D/G and top-300 selection must not silently remove these marked targets under the proposed boundary. Missing required target/profile/vector data is an error, not an absent carer.
5. A marked target discovered outside P whose r0_i>=Theta is admitted with its direct score and X=0 (direct recovery). Record its admission route separately. It does not become a new social seed in this pass: one-hop expansion is from the fixed A_seed only. A marked target outside A_seed with r0_i<Theta forms B. Thus the final admitted direct set may include recovered A targets; full-population A coverage is still not guaranteed by the MVP cuts.
6. For i in B, W_X=sum_j alpha_j*w_Xj; delta_hi=W_X*t_hi. Accept a full addition only when r0_i+delta_hi<=r0_h (existing 1e-12 equality tolerance). x_i=max(accepted delta_hi union {0}); R_i=r0_i+x_i. Reject overflowing additions entirely, without partial caps. Maximize per recipient across eligible sources, not by choosing only one carer from a source's links. All marked carers enter regardless of final score; zero tie/W_X or rejected additions leave B in the public at baseline r0. No X for direct members and no social propagation from a discovered target.
7. Normalize combined R/E once over the resulting unique public using the current rounding and stable-order contract. E has its existing single blended education floor and no Education/Experience weights. The flag/cuts change membership and means, so existing publics cannot be relabeled/recomputed silently. Explicit Join remains uncapped by the automatic 300-candidate approximation.

The direct-recovery edge case above is a concrete proposed resolution of the conflict between retained approximation and the earlier global direct-cohort definition. It preserves no-X for any person already reaching Theta, rather than giving an indirectly discovered but directly affected carer an X bonus.
